# STEM-проєкт: порівняння класичних пайплайнів обробки супутникових знімків

«Усі методи обробки реалізовано вручну (без OpenCV та інших бібліотек комп'ютерного зору, без методів ШІ та машинного навчання).»
Індивідуальний проєкт, **варіант 2**: два пайплайни обробки зображень (кожен із трьох стадій
різних категорій) і порівняння їхньої стійкості до спотворень. Бібліотека Pillow використовується лише для
читання й запису файлів.

## Ідея
Знімки з набору UC Merced штучно спотворюються (гаусів шум, імпульсний шум, серпанок), потім
кожен пайплайн обробляє чисте й спотворене зображення. Якість оцінюється тим, наскільки
результат на спотвореному знімку збігається з результатом на чистому (метрики PSNR, SSIM, MSE;
для масок IoU і коефіцієнт Дайса).

## Пайплайни
| Пайплайн | Стадії | Категорії методів |
|---|---|---|
| `pipeline1` | білатеральний фільтр -> вирівнювання гістограми -> поріг Оцу | фільтрація, гістограмна корекція, сегментація |
| `pipeline2` | фільтр Вінера -> підвищення насиченості (HSV) -> колірна сегментація | фільтрація, колірні перетворення, сегментація |
| `pipeline2m` | `pipeline2` + морфологічне очищення маски | + морфологія |

Методи відрізняються від реалізованих у лабораторних роботах 5-6.

## Дані
У `data/original/` лежать 100 знімків набору UC Merced Land Use (10 класів по 10 знімків:
agricultural, beach, buildings, denseresidential, forest, golfcourse, harbor, parkinglot,
river, runway). Знімки суспільного надбання (USGS National Map Urban Area Imagery).

Джерело: Yang Y., Newsam S. *Bag-Of-Visual-Words and Spatial Extensions for Land-Use
Classification*. ACM SIGSPATIAL GIS, 2010. Офіційний сайт набору
(weegee.vision.ucmerced.edu) може бути недоступним, тоді архів можна взяти з дзеркала на
Hugging Face (`SatwikKambham/uc_merced_land_use`).

## Швидка перевірка 
```
python -m unittest discover -s tests -t .
python main.py prepare
python main.py degrade
python main.py stage bilateral data/degraded/forest00__gauss_low.png out.png --reference data/prepared/forest00.png
```
Очікуваний результат: `Ran 95 tests ... OK`; `Підготовлено зображень: 100`; 400 рядків із PSNR;
і наприкінці порівняння метрик до й після стадії (PSNR зростає приблизно з 28,8 до 34,4 дБ,
SSIM із 0,79 до 0,90).


## Запуск (по порядку)
```
python main.py prepare            # квадрат із центру, зміна розміру до 256x256 (data/prepared)
python main.py degrade            # 4 спотворені копії кожного знімка (data/degraded)
python main.py run pipeline1      # близько 17 хв
python main.py run pipeline2      # близько 12 хв
python main.py run pipeline2m     # близько 14 хв
python main.py compare            # середні метрики за пайплайном, спотворенням і стадією
python main.py analyze            # порівняння за класами та парне порівняння
```
Додаткові команди:
```
python main.py metrics A.png B.png                       # MSE, PSNR, SSIM для двох файлів
python main.py stage bilateral noisy.png out.png --reference clean.png   # одна стадія
```
Доступні стадії: `bilateral`, `wiener`, `equalize`, `saturation`, `otsu`, `color_segment`,
`morphology`. Інший файл конфігурації: `python main.py --config my.json prepare`.

Результати (таблиці метрик, проміжні зображення кожної стадії) зберігаються в `results/`.
Таблиці `results/*.csv` і `results/*.txt`, які потрапили в репозиторій, це результати
останнього повного запуску.

## Конфігурація (`config.json`)
Усі параметри задаються в конфігурації, без зміни коду.

| Параметр | Значення |
|---|---|
| `seed` | початкове число випадкових величин: шум щоразу однаковий |
| `image_size` | сторона знімків після підготовки |
| `paths` | папки з даними й результатами |
| `degradations` | спотворення: `gaussian` (variance), `impulse` (prob), `haze` (contrast) |
| `metrics` | вікно і крок для SSIM |
| `stages` | параметри стадій: `bilateral`, `wiener`, `saturation`, `color_segment`, `morphology` |
| `pipelines` | списки стадій пайплайнів |
| `save_intermediate` | чи зберігати проміжні зображення стадій |

## Метрики й еталон
- **MSE, PSNR, SSIM** (реалізовано вручну): `metrics.py`; SSIM рахується за яскравістю у вікнах
  8x8 з кроком 4.
- **IoU, коефіцієнт Дайса** для масок: `mask_metrics.py`.
- **Еталон стадії** це результат тих самих стадій на чистому знімку: так порівняння не
  штрафує стадії, які змінюють навіть чисте зображення (наприклад, вирівнювання гістограми).
  Додатково записуються PSNR і SSIM відносно чистого оригіналу.
- **Парне порівняння** (`analyze`): для кожної пари пайплайнів різниця метрики на тому самому
  знімку, її 95 % інтервал (нормальне наближення) і частка знімків, де другий пайплайн кращий.

## Тести
```
python -m unittest discover -s tests -t .
```
Для кожної стадії та кожного пайплайна є тест на малому зображенні з результатом, обчисленим
вручну; окремо перевірено крайні випадки (порожні й пошкоджені файли, чорно-білі зображення,

## Статичний аналіз
```

```
Файл `.pylintrc` дозволяє короткі імена змінних `x`, `y`, `c` (загальноприйняті в обробці
зображень) і підвищує ліміти на кількість локальних змінних для чисельних алгоритмів.

## Обмеження
- Маски двох пайплайнів виділяють різне (яскраве і зелене), тому IoU вимірює **стійкість до
  спотворень**, а не точність виділення об'єктів.
- Колірна сегментація орієнтована на зелений діапазон відтінків (40-170 градусів). На
  сухих полях і темних лісах із синюватим відтінком маска порожня або занижена.
- Фільтри мають фіксовані параметри для всіх рівнів шуму (наприклад, `sigma_range` білатерального).
- Вибірка містить по 10 знімків на клас, тому за класами порівнюються лише середні.
- Пороги колірної сегментації підібрані на підвибірці з 10 знімків, перевірка на всіх 100.
